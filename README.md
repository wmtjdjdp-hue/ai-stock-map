# AI関連株コード辞典 v53 APIなしAI調査サポート

## v53で追加した内容
- API契約なしで使える「AI調査サポート」ページを追加
- ChatGPT / Google Gemini / Claude / Genspark を外部で開くリンクを追加
- ティッカー情報から、AIに貼る質問文を自動生成
- ティッカー検索ページにも「APIなしAI調査サポート」欄を追加
- 外部AIの回答を貼り付ける一時メモ欄を追加
- 質問文とAI回答メモをテキストでダウンロード可能
- OpenAI API / Gemini API / Claude APIなどのAPIキーは不要

## 触っていない部分
- AI関連図のカテゴリ自動追加
- Googleスプレッドシート保存
- 全銘柄一覧
- ティッカー検索の既存ロジック
- 株価・PER・PBRなどの自動取得処理

# AI関連株コード辞典 v52 Dynamic AI Categories

## v52で修正した内容
- AI関連図の基本構造はそのまま維持
- GPU / メモリー / 冷却 / 電力 / データセンター / 半導体 の6カテゴリはそのまま
- Googleスプレッドシートや一時登録銘柄に新しいカテゴリがある場合、AI関連図に自動でカテゴリ枠を追加
- 追加カテゴリも横3つ並びのティッカー小枠で表示
- ティッカーコードを押すとティッカー検索ページへ移動する機能は維持
- 全銘柄一覧、Google保存、戻るボタンなど他の機能は触っていません
