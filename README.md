# AI関連株コード辞典 v57 Earnings Import RE Fix

## v57で修正した内容
- 決算日変換に使う re モジュールが未importだった問題を修正
- これが原因で 1769299200 のような数字が日本式日付へ変換されていませんでした
- 決算日カードは fmt_jp_date() を直接使うように修正
- 表示例: 1769299200 → 2026年1月25日
- 他のロジック、AI関連図、全銘柄一覧、Google保存、AI調査サポートは触っていません
